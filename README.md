# app-releases
개인용 안드로이드 앱 apk 배포 (치지직 방송 알림, 엔드필드 출석).

`netmonitor/`에는 네트워크 모니터 앱의 소스 코드가 있고, 나머지 앱은 apk만 있습니다.

## 네트워크 모니터 (`netmonitor/`)

속도 측정 사이트처럼 회선 속도(다운로드·업로드·핑)를 재서 주식 차트처럼 쌓아 보여 주고, 데이터 사용량도 따로 기록하는 앱입니다.

### APK 내려받기 (휴대폰만으로)

1. 이 저장소의 **Releases**에서 이름이 `netmonitor-`로 시작하는 가장 최근 항목을 엽니다.
2. **Assets**의 `netmonitor.apk`를 눌러 내려받습니다.
3. 받은 파일을 눌러 설치합니다. 처음에는 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.
4. 앱을 열고 알림 권한을 허용합니다. 거부해도 기록은 되지만 알림창 속도 표시가 안 보입니다.

`netmonitor/` 아래 파일이 push될 때마다 자동으로 빌드되어 Releases에 새 항목으로 올라갑니다.
빌드마다 같은 키(`netmonitor/debug.keystore`)로 서명하므로 새 APK를 그대로 덮어 설치하면 기록이 유지됩니다.

### 쓰는 법

**속도 측정 탭**

- **측정 시작**을 누르면 핑 → 다운로드 → 업로드 순서로 약 20초 동안 잽니다. 도중에 **중지**할 수 있습니다.
- 결과는 자동으로 저장되고 아래 차트에 쌓입니다. 파란 선이 다운로드, 주황 선이 업로드(Mbps)입니다.
- 차트 위 큰 숫자는 가장 최근 다운로드 속도, 그 아래는 직전 측정 대비 증감입니다(늘면 빨강, 줄면 파랑).

**사용량 탭**

- 위쪽 카드는 지금 실제로 오가는 데이터 속도입니다. 아무것도 안 하면 0에 가깝고, 영상을 보면 올라갑니다.
- **사용량 기록 스위치**: ON이면 앱을 닫아도, 재부팅해도 계속 기록하고 알림창에 속도를 띄웁니다. OFF면 멈추고 재부팅 뒤에도 꺼진 채로 둡니다.
- 차트는 파란 선이 Wi-Fi, 주황 선이 모바일 누적 사용량입니다. 큰 숫자가 기간 총 사용량, 그 아래가 직전 기간 대비 증감입니다.

두 차트 모두 기간(1시간 / 오늘 / 7일 / 30일)을 바꿀 수 있고, 터치하면 그 시점의 값이 보이며, 두 손가락으로 가로 확대한 뒤 끌어서 이동합니다.

### 알아 둘 점

- 속도 측정은 Cloudflare의 공개 측정 서버(speed.cloudflare.com)와 데이터를 주고받습니다. 한 번에 수십~수백 MB를 쓸 수 있으니 모바일 데이터에서는 주의하세요.
- 속도 측정은 버튼을 누를 때만 합니다. 자동으로 반복 측정하지 않습니다.
- Wi-Fi 사용량은 "전체 − 모바일"로 계산하므로 VPN·이더넷·테더링 사용량이 Wi-Fi 쪽에 섞일 수 있습니다.
- 사용량 기록 스위치가 OFF이거나 앱이 강제 종료된 동안의 사용량은 기록되지 않습니다.
- 배터리 절약 기능이 앱을 자주 끄는 기기라면 설정에서 이 앱의 배터리 사용을 "제한 없음"으로 바꾸세요.
- 사용량 기록은 62일이 지나면 지워집니다.
