# app-releases
개인용 안드로이드 앱 apk 배포 (치지직 방송 알림, 엔드필드 출석).

`netmonitor/`에는 네트워크 모니터 앱의 소스 코드가 있고, 나머지 앱은 apk만 있습니다.

## 네트워크 모니터 (`netmonitor/`)

와이파이·모바일 데이터의 실시간 속도를 보여 주고, 사용량을 쌓아 주식 차트처럼 그려 주는 앱입니다.

### APK 내려받기 (휴대폰만으로)

1. GitHub에서 이 저장소의 **Actions** 탭 → **NetMonitor APK 빌드** → 맨 위(가장 최근) 초록색 실행을 엽니다.
2. 아래쪽 **Artifacts**의 `netmonitor-debug-apk`를 눌러 내려받습니다. (GitHub 로그인 필요, 90일 뒤 사라짐)
3. 받은 zip을 파일 앱에서 풀고 `app-debug.apk`를 눌러 설치합니다. 처음에는 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.
4. 앱을 열고 알림 권한을 허용합니다. 거부해도 기록은 되지만 알림창 속도 표시가 안 보입니다.

`netmonitor/` 아래 파일이 push될 때마다 자동으로 빌드됩니다. Actions 탭의 **Run workflow**로 직접 돌릴 수도 있습니다.
빌드마다 같은 키(`netmonitor/debug.keystore`)로 서명하므로 새 APK를 그대로 덮어 설치하면 기록이 유지됩니다.

### 쓰는 법

- **측정·기록 스위치**: ON이면 앱을 닫아도, 재부팅해도 계속 기록합니다. OFF면 측정과 알림을 멈추고 재부팅 뒤에도 꺼진 채로 둡니다.
- **기간**: 1시간 / 오늘 / 7일 / 30일. 위쪽 큰 숫자가 기간 총 사용량, 그 아래가 직전 기간 대비 증감입니다(늘면 빨강, 줄면 파랑).
- **차트**: 파란 선이 Wi-Fi, 주황 선이 모바일 누적 사용량입니다. 터치하면 그 시점의 값이 보이고, 두 손가락으로 가로 확대, 확대한 뒤 끌어서 이동합니다.

### 알아 둘 점

- Wi-Fi 사용량은 "전체 − 모바일"로 계산하므로 VPN·이더넷·테더링 사용량이 Wi-Fi 쪽에 섞일 수 있습니다.
- 스위치가 OFF이거나 앱이 강제 종료된 동안의 사용량은 기록되지 않습니다.
- 배터리 절약 기능이 앱을 자주 끄는 기기라면 설정에서 이 앱의 배터리 사용을 "제한 없음"으로 바꾸세요.
- 기록은 62일이 지나면 지워집니다.
